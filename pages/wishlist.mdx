# Wishlist

Increase engagement and sales on your stores by allowing customers to save their desired products for later purchase.

Sledge provides several widgets you can use to integrate it with your store.

Available widgets :

- [Badge](#badge)
- [Trigger](#trigger)
- [Button Detail](#button-detail)
- [Widget](#widget)
- [Flyout Widget](#flyout-widget)

<Callout type="info">
  If you're using `Hydrogen` or `Next.js`, <br/> make sure to install the `@sledge-app/react-wishlist` package first.
</Callout>

```sh copy
npm i @sledge-app/react-wishlist
```
