# Track User Interactions

When using Custom Components you might want to track user interactions like add to cart or product click on a [Product Card](/custom-components/global#product-card) so that the information can be stored in the [Dashboard](/backend-instant-search-and-product-filters#dashboard).

Available trigger functions for support Track User Interations :

- [Add to Cart](#add-to-cart)
- [Product Click](#product-click)

You can include a trigger function in your Custom Component by following example code below :

        import { Link } from '@remix-run/react';

    <Tab>
        See the [API reference](/sledge-app-api#api-reference-9) of `productClickTrigger`.

        ```html {12-19, 26-30} showLineNumbers copy
        ...
        <div data-component="instant-search-icon-widget">
            <div
                data-component="custom-components"
                data-render-product-card="renderProductCard"
            ></div>
        </div>
        ...

        <script>
            function productClickTrigger({ sourceApp, productId, url }) {
                window.sledge
                    .productClickTrigger({
                        sourceApp,
                        productId
                    })
                    .then(() => {
                        window.location.href = url;
                    });
            }

            function renderProductCard({ product, sourceApp }) {
                ...
                return `
                ...
                <a href="#" onclick="productClickTrigger({
                    sourceApp: '${sourceApp}',
                    productId: '${product.id}',
                    url: '/products/${product.handle}'
                })">
                    ${product.title}
                </a>
                ...`;
            }
        </script>
        ```
