##### Show selected sort on mobile

This option allows you to set the sort placeholder on the mobile version based on either the selected sort or localization settings.

<Image
  className="mt-7 rounded-[24px] w-auto max-h-[359px] border border-[rgba(67,198,172,1)]"
  src={IMAGE_BACKEND_INSTANT_SEARCH_AND_PRODUCT_FILTERS_CUSTOMIZE_GENERAL_POINT_2_SUB_1}
  alt="sledge-image-docs"
/>

Enable this option if you want the placeholder on the sort button to match the selected sorting method. For example :

<Image
  className="mt-7 rounded-[24px] w-auto max-h-[359px] border border-[rgba(67,198,172,1)]"
  src={IMAGE_BACKEND_INSTANT_SEARCH_AND_PRODUCT_FILTERS_CUSTOMIZE_GENERAL_POINT_2_SUB_1_1}
  alt="sledge-image-docs"
/>

Or leave it disabled if you want the sort button's placeholder to be based on localization. For example :

<Image
  className="mt-7 rounded-[24px] w-auto max-h-[359px] border border-[rgba(67,198,172,1)]"
  src={IMAGE_BACKEND_INSTANT_SEARCH_AND_PRODUCT_FILTERS_CUSTOMIZE_GENERAL_POINT_2_SUB_1_2}
  alt="sledge-image-docs"
/>

You can locate the `Mobile Sort Placeholder` under `General` > `Translation` > `General`.

  className="mt-7 rounded-[24px] w-auto max-h-[359px] border border-[rgba(67,198,172,1)]"
