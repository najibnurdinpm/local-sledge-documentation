# Global

If you prefer to fetch Sledge data on the server instead doing fetch on the client browser. You can use Sledge's API package called [@sledge-app/api](/sledge-app-api).

Basically the steps as simple as fetching data on server then pass that data to Sledge components, follow steps by steps below to see how to do the server side fetching.

## Gid Parser (optional)

Parses [Shopify Global ID (GID)](https://shopify.dev/api/usage/gids) and returns the resource type and ID.

```ts filename="lib/shopify/parse-gid.ts" showLineNumbers copy
export default function parseGid(gid: string | undefined) {
  if (!gid?.includes("/")) return { id: gid || "", type: undefined };

  const arr = gid.split("/");
  const id = arr[arr.length - 1] || "";
  const type = arr[arr.length - 2];

  return { id, type };
}
```
