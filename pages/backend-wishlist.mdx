# Using Backend

Monitor your customer activity on the wishlist app from here. Don't miss out on what products your customers want most and find your potential customers.

Sledge provides several menus you can use to monitoring and customizing app.

- [Dashboard](#dashboard)
- [Activity](#activity)
- [Customer](#customer)
- [Products](#products)
- [Customize](#customize)

## Dashboard

Wishlist dashboard page provides statistical data of wishlist activity, like addition for customer add product to wishlist activity, customer for customer do wishlist activity, product for product that have been added to the wishlist, and add to cart for add cart activity from wishlist page.

/>

## Activity

Wishlist activity page provides a list of the latest wishlist activities.
activities list:
- `New` for first wishlist activity of user
- `Add` for adding wishlist activity
- `Delete` for removing wishlist activity
- `Clear` for clearing wishlist activity
