# Product Review

Show the best review of your products with the easy and customizable product review widgets to gain customer trust and boost your store sales.

Sledge provides several widgets you can use to integrate it with your store.

Available widgets :

- [Rating](#rating)
- [Widget](#widget)
- [Happy Customers Page](#happy-customers-page)
- [Trust Badge](#trust-badge)
- [Sticky Sidebar Widget](#sticky-sidebar-widget)
- [Snippet Carousel Widget](#snippet-carousel-widget)

<Callout type="info">
  If you're using `Hydrogen` or `Next.js`, <br /> make sure to install the
  `@sledge-app/react-product-review` package first.
</Callout>

```sh copy
npm i @sledge-app/react-product-review
```
