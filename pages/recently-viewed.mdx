# Recently Viewed

Designed to increase user engagement and optimize the shopping experience by providing quick access to previously viewed products.

Sledge provides several widgets you can use to integrate it with your store.

Available widgets :

- [Recently Viewed](#recently-viewed)

<Callout type="info">
  If you're using `Hydrogen` or `Next.js`, <br/> make sure to install the `@sledge-app/react-product-recommendation` package first.
</Callout>

```sh copy
npm i @sledge-app/react-product-recommendation
```

## Recently Viewed

Recently Viewed is an Product Recommendation's widget you can use to see a list of products that you have previously opened, this widget can be placed on all your store pages. <br/><br/>
