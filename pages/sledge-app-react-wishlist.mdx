# @sledge-app/react-wishlist

You can use our React-built widget by using the `@sledge-app/react-wishlist` package.

`@sledge-app/react-wishlist` provides several components you can use to integrate it with your store.

Available components :

- [Badge](#badge)
- [Trigger](#trigger)
- [Button Detail](#buttondetail)
- [Widget](#widget)


## `Badge`

Badge is a Wishlist's widget you can use to display your wishlist's total in a small text box or an icon.<br/>

[See example](/wishlist#badge) <br/><br/>

### Anatomy

```tsx showLineNumbers copy
import { Badge } from "@sledge-app/react-wishlist";
import SledgeProductCard from "~/components/SledgeProductCard";

export default function SledgeWishlistBadge() {
  return (
    <Badge
      useProxyUrl={false}
      position="left"
      useWishlistFlyout={false}
      urlWishlistWidget={'/pages/wishlist'}
    />
  );
}
```

### API reference

#### <span className="text-xl font-bold">`useProxyUrl`</span>

Define the url widgets on page that should be displayed (custom or proxy).

- Type: `boolean`
- Default: `false`

#### <span className="text-xl font-bold">`position`</span>

Define a widget position for Badge.

- Type: `none` | `left` | `right` | `bottom-left` | `bottom-right`
- Default: `none`

#### <span className="text-xl font-bold">`useWishlistFlyout`</span>

Display your wishlist items in a sliding panel by activating the [Wishlist - Flyout Widget](/wishlist#flyout-widget).

- Type: `boolean`
- Default: `false`

#### <span className="text-xl font-bold">`urlWishlistWidget`</span>

Fill up the route URL page where your Wishlist widget is located.

<div>e.g: `https://your-online-store.com/{value}`</div>

- Type: `string`

## `Widget`

You can use Widget to display list data of user's wishlist.<br/>

[See example](/wishlist#list)<br/><br/>

<Image
  src={ IMAGE_APPS_WISHLIST_LIST }
  alt="List"
  width="1339"
  height="749"

### Anatomy

```tsx showLineNumbers copy
import { Widget, WidgetHeader } from "@sledge-app/react-wishlist";

export default function WishlistWidget() {
  return (
    <Widget.Root
      query={{
        shareId: "share",
      }}
      width="1180px"
      limitOptions={[12, 24, 36, 48, 120]}
      onAfterAddWishlist={(state) => {
        // Your custom function
      }}
      onAfterRemoveWishlist={(state) => {
        // Your custom function
      }}
      onAfterRenderProduct={(state) => {
        // Your custom function
      }}
    >
      <WidgetHeader>
        <WidgetHeader.Title text="My Wishlist" />
        <WidgetHeader.SearchForm placeholder="Search product" />
        <WidgetHeader.ClearTrigger buttonText="Clear Wishlist" />
        <WidgetHeader.ShareTrigger buttonText="Share Wishlist" />
        <WidgetHeader.Sort />
        <WidgetHeader.Limit />
      </WidgetHeader>
      <Widget.List gridType="large" />
    </Widget.Root>
  );
}
```

### API reference

#### <span className="text-2xl gradient-text-primary font-bold">`<Widget.Root>`</span>

<br />
##### <span className="text-xl font-bold">`query.shareId`</span>

Fill up your unique queryParam name for share id.

<div>e.g: `https://your-online-store.com/pages/wishlist/?{value}=`</div>

- Type: `string`
- Default: `'share'`

<br />
##### <span className="text-xl font-bold">`width`</span>

Customize max width of element.

- Type: `string`
- Default: `'1180px'`

<br />
##### <span className="text-xl font-bold">`limitOptions`</span>

Customize limit options in widget.

- Type: `string[] | number[]`
- Default: `[12, 24, 36, 48, 120]`

<br />
##### <span className="text-xl font-bold">`onAfterAddWishlist(state: boolean)`</span>

Running using your own custom function

- Type: `function`
- Required: `false`

<br />
##### <span className="text-xl font-bold">`onAfterRemoveWishlist(state: boolean)`</span>

Running using your own custom function

- Type: `function`
- Required: `false`

<br />
##### <span className="text-xl font-bold">`onAfterRenderProduct(state: boolean)`</span>

Running using your own custom function

- Type: `function`
- Required: `false`

#### <span className="text-2xl gradient-text-primary font-bold">`<WidgetHeader.Title>`</span>

<br />
##### <span className="text-xl font-bold">`text`</span>

Customize header title in widget

- Type: `string`
- Default: `'My Wishlist'`

#### <span className="text-2xl gradient-text-primary font-bold">`<WidgetHeader.SearchForm>`</span>

<br />
##### <span className="text-xl font-bold">`placeholder`</span>

Customize placeholder search form in widget

- Type: `string`
- Default: `'Search product...'`

#### <span className="text-2xl gradient-text-primary font-bold">`<WidgetHeader.ClearTrigger>`</span>

<br />
##### <span className="text-xl font-bold">`buttonText`</span>

Customize clear button title in widget

- Type: `string`
- Default: `'Clear Wishlist'`

#### <span className="text-2xl gradient-text-primary font-bold">`<WidgetHeader.ShareTrigger>`</span>

<br />
##### <span className="text-xl font-bold">`buttonText`</span>

Customize share button title in widget

- Type: `string`
- Default: `'Share Wishlist'`

#### <span className="text-2xl gradient-text-primary font-bold">`<Widget.Limit>`</span>

<br />
##### <span className="text-xl font-bold">`gridType`</span>

Customize grid size product card in widget

- Type: `'small' | 'medium' | 'large'`
- Default: `'large'`
