# Custom Components

Sledge provides default layout and components like product cards, instant search results, etc. We understand that sometimes you need a fully custom layout and components to match with your store needs, so Sledge allows you to build your own Custom Components.

With Custom Components you can build your own layout based on your store branding or design, display additional components, etc. Navigate through following examples to see how flexible Custom Components is or read [its API reference](/sledge-app-core#customcomponents).
