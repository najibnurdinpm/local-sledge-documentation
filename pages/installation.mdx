# Installation

To get started, pick one of the following step-by-step quickstart guidelines. If you're using headless storefront there are 2 options you can pick : [Hydrogen](/installation/hydrogen) or [Next.js Commerce](/installation/nextjs).

For [Liquid](/installation/liquid), There are 2 options that you can pick,
If you want to easily install Sledge's app, you can pick Theme Customizer or pick Code for more advanced settings.
